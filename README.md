**Staphylococcus aureus WGS Nextflow Pipeline**

An automated whole-genome sequencing (WGS) workflow for Staphylococcus aureus, developed using Nextflow to organize read quality control, trimming, genome assembly, assembly assessment, genome completeness evaluation, and functional annotation.

**Project Overview**

This project analyzes sequencing dataset ERR16986790, associated with Staphylococcus aureus from horses in Norway.

The workflow combines bioinformatics tools into a reproducible pipeline and includes downstream functional annotation and KEGG pathway mapping.

**Workflow**

1. Read Download** — Retrieve sequencing reads.
2. Raw Read Quality Control** — Assess read quality using FastQC.
3. Read Trimming** — Remove low-quality bases and adapter sequences using fastp.
4. Post-trimming Quality Control** — Reassess the trimmed reads using FastQC.
5. Genome Assembly** — Assemble the reads using SPAdes.
6. Assembly Assessment** — Evaluate assembly statistics using QUAST.
7. Genome Completeness** — Assess conserved marker recovery using BUSCO.
8. Genome Annotation** — Predict and annotate genomic features using Prokka.
9. Functional Annotation** — Assign protein functions using GhostKOALA.
10. Pathway Mapping** — Explore KEGG pathway associations using KEGG Mapper.

**Key Results**

| Metric | Result |
|---|---:|
| Genome assembly length | 2,810,631 bp |
| Number of contigs (minimum 200 bp) | 60 |
| BUSCO completeness | 100% |
| Prokka-predicted proteins | 2,598 |
| Proteins with at least one KO assignment | 1,526 |
| Distinct KO identifiers | 1,338 |

**Interpretation**: BUSCO completeness represents recovery of conserved markers in the reported dataset. It does not independently demonstrate that the assembly is error-free or uncontaminated. KO assignments and pathway mappings suggest functional associations but do not by themselves demonstrate gene expression, pathogenicity, or antimicrobial resistance.

**Requirements**

- Linux or WSL Ubuntu
- Java compatible with your installed Nextflow version
- Nextflow
- FastQC, fastp, SPAdes, QUAST, BUSCO, and Prokka
- Appropriate databases and configuration for BUSCO and annotation tools

Check each tool's installation requirements and the settings in `nextflow.config` before running the workflow.
**
Run the Pipeline**

Clone the repository:

```bash
git clone https://github.com/Mdsaihan21/staphylococcus-aureus-wgs-nextflow-pipeline.git
cd staphylococcus-aureus-wgs-nextflow-pipeline
```

Run the workflow:

```bash
nextflow run main.nf
```

Resume a previous run:

```bash
nextflow run main.nf -resume
```

The workflow requires the appropriate tools, databases, and configuration to be available in the execution environment.

Downstream Functional Analysis

Protein sequences generated by Prokka were used for GhostKOALA functional annotation. KO assignments were subsequently used with KEGG Mapper to explore pathway associations.

Some downstream analyses may involve external web services or manual steps and may not be fully automated by the Nextflow workflow.

**Reproducibility and Limitations**

- Results depend on the input data, tool versions, databases, and configuration.
- Review `nextflow.config` and the pipeline processes before running on a new system.
- Functional annotations are computational predictions and should be interpreted accordingly.
- Verify the dataset metadata and tool versions when reproducing the analysis.
